qpart — Mode d'emploi pour ajouter une partition

Cet article explique exactement ce que je (l'assistant) attends quand vous me demandez d'ajouter une partition interactive, et les étapes à suivre pour que tout fonctionne sans retours. Collez cette URL à côté de vos demandes : /materielchansons/qpart.html.

1) Fichiers à créer / emplacement

  • La page HTML interactive doit être placée dans materielchansons/ : ex. materielchansons/ma-chanson-partition.html.
  • Les fichiers audio / PDF associés vont dans materielchansons/... (sous-dossiers possibles).
  • Les modifications visibles par l'interface listée sont faites dans data/partitions.json.

2) Template de page HTML (copier/coller)

Utilisez exactement le même modèle que les autres partitions (header + nav + bloc d'astuce + iframe). Exemple minimal à coller dans materielchansons/nom-partition-partition.html :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Partition interactive : TITRE</title>
  <link href="https://fonts.googleapis.com/css2?family=Lobster&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="../assets/css/style.css">
</head>
<body class="internal-page">
  <!-- header/nav identique aux autres partitions -->
  <main class="main-content" style="max-width:900px;...">
    <h2 style="text-align:center;">Partition : TITRE</h2>
    <div class="tip">Astuce ...</div>
    <iframe src="VOTRE_IFRAME_EMBED" height="480" width="100%" frameborder="0" allowfullscreen allow="autoplay; midi" loading="lazy"></iframe>
    <div>Lien Flat : <a href="URL_FLAT">TITRE</a></div>
  </main>
</body>
</html>

3) Entrée à ajouter dans data/partitions.json

Ajoutez un objet dans le tableau data/partitions.json. Exemple :

{
  "title": "Be My Husband",
  "interactive_link": "materielchansons/be-my-husband-partition.html"
}

Si vous avez pistes audio ou documents, vous pouvez ajouter les champs recordings et documents (voir les autres entrées dans le fichier pour modèle).

4) Conventions de nommage et encodage

  • Éviter (si possible) les caractères inhabituels dans les noms de fichiers : préférez a-z A-Z 0-9 - _ . pour éviter les problèmes d'URL et d'encodage (espaces, accents ou emoji posent parfois problème).
  • Si vous gardez des espaces/accents, encodez les liens ou laissez le site faire l'encodage (nous le faisons pour vous), mais testez toujours le lien dans le navigateur.

5) Checklist avant de me demander d'ajouter la partition

  • Page HTML placée dans materielchansons/, nommée ...-partition.html.
  • Entrée ajoutée à data/partitions.json (title + interactive_link correct).
  • Test local : ouvrez la page via Live Server et vérifiez que l'iframe s'affiche.
  • Vérifiez les chemins relatifs dans la page (utilisez ../assets/...).
  • Faites un git add/commit ou laissez‑moi le faire si vous préférez. Poussez vers la branche refonte-logique si vous voulez que je déploie/teste en ligne.

6) Ajout par l'assistant — que je peux faire pour vous

Quand vous me demandez "Ajoute la partition X", joignez :

  • Le contenu HTML (ou uniquement l'iframe Flat embed si vous voulez que je crée la page).
  • Le texte exact à mettre dans data/partitions.json (title + interactive_link éventuellement recordings/documents).
  • Précisez si vous voulez que je fasse le commit/push pour vous ou si vous préférez le faire.

7) Déploiement & cache

Après push, le site peut mettre du temps à actualiser côté visiteurs si un cache Cloudflare ou navigateur sert une ancienne version. Pour éviter les problèmes :

  • Versionnez/renommez vos fichiers quand vous changez d'asset (ex. main.abcdef.js) ou incrémentez un ?v= sur les URLs.
  • Si vous utilisez Cloudflare, activez temporairement Development Mode pour vérifier le rendu, ou purgez l'URL précise.

8) Exemple complet - ce que vous pouvez m'envoyer

-- iframe embed (copier)
<iframe src="...flat.io/embed/ID?sharingKey=..." height="480" width="100%" frameborder="0" allowfullscreen allow="autoplay; midi"></iframe>

-- JSON à ajouter (copier)
{
  "title": "NOM DE LA CHANSON",
  "interactive_link": "materielchansons/nom-de-la-chanson-partition.html"
}

-- Indiquez si vous voulez que j'ajoute le fichier HTML ou si vous l'avez déjà créé.

Si vous voulez, je peux aussi :

  • Vérifier la page localement via Live Server avant commit.
  • Effectuer le commit et le push pour vous (précisez le message de commit).
  • Ajouter automatiquement une miniature ou des métadonnées supplémentaires si vous fournissez une image.

Collez ici votre iframe + le JSON quand vous êtes prêt·e, ou dites "Fais-le pour moi" et je créerai la page et mettrai à jour data/partitions.json.
